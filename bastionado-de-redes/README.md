# Bastionado de redes y sistemas

Técnicas para reducir la superficie de ataque de redes y sistemas mediante
un diseño y una configuración seguros desde el principio.

## Contenidos
- **Diseño de planes de securización:** evaluación del estado de seguridad,
  estándares y guías de buenas prácticas (CIS, ENS, ISO 27001) y planificación
  de medidas.
- **Diseño de redes seguras:** segmentación, VLAN, cortafuegos, DMZ, VPN,
  IDS/IPS y control de acceso a la red.
- **Configuración de sistemas:** endurecimiento (hardening) de sistemas
  operativos y servicios, gestión de usuarios, permisos, parches y registros.
