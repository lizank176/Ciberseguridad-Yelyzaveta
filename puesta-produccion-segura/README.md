# Puesta en producción segura

Cómo desarrollar, probar y desplegar aplicaciones asegurando que no
introducen vulnerabilidades en el entorno de producción.

## Contenidos
- **Detección y corrección de vulnerabilidades en aplicaciones:** OWASP Top 10,
  análisis estático y dinámico (SAST/DAST), revisión de código y
  corrección de fallos habituales (inyección, XSS, autenticación débil...).
- **Despliegue seguro de aplicaciones:** entornos y configuración segura,
  gestión de secretos, contenedores, CI/CD y seguridad en el ciclo de vida
  del software (DevSecOps).
